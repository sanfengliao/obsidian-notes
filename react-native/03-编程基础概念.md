# 01 · 编程基础概念

这一篇讲「编程这件事本身」。AI 写的代码无论多复杂，拆到底都是这几个概念。看懂它们，你就能大致读懂任何一段代码在干嘛。

---

## 变量（Variable）

**大白话**：给一个东西起个名字，方便以后用它、改它。就像贴了标签的**盒子**，盒子里装东西，标签是名字。

```js
let userName = "小明"   // 盒子叫 userName，里面装了 "小明"
let age = 20            // 盒子叫 age，里面装了 20
age = 21                // 把 age 盒子里的东西换成 21
```

- `let` / `const` 是「声明盒子」的方式，详见 [[04-JavaScript与TypeScript速查]]。
- `=` 不是「等于」，是「把右边的放进左边的盒子」，叫**赋值**。

---

## 数据类型（Data Type）

盒子里能装不同种类的东西，常见这几样：

| 类型 | 例子 | 说明 |
|------|------|------|
| 字符串 string | `"你好"`、`'abc'` | 一段文字，必须用引号包起来 |
| 数字 number | `20`、`3.14`、`-1` | 数值，不加引号 |
| 布尔 boolean | `true`、`false` | 只有「真/假」两种，用来做判断 |
| 空 null | `null` | 「明确地没有东西」 |
| 未定义 undefined | `undefined` | 「还没赋值」，盒子是空的 |
| 数组 array | `[1, 2, 3]` | 一排盒子，按顺序装多个东西 |
| 对象 object | `{name: "小明", age: 20}` | 一个有格子的盒子，每格有名字 |

> AI 说「这是个字符串」「返回一个对象」，就是指这个。

---

## 函数（Function）

**大白话**：一段**可以反复使用的「菜谱」**。你给它一些原料（输入），它按步骤加工，最后端出一道菜（输出）。

```js
// 定义一个菜谱叫 greet，需要一份原料 name
function greet(name) {
  return "你好，" + name   // 端出来的菜
}

greet("小明")   // 输出："你好，小明"
greet("小红")   // 输出："你好，小红"
```

几个词：
- **参数（Parameter / Argument）**：传进去的原料（上面的 `name`）。
- **返回值（Return value）**：端出来的结果（`return` 后面的东西）。
- **调用（Call）**：实际用一次这个函数（`greet("小明")`）。

> 类比：函数像**榨汁机**。你扔进去水果（参数），它榨出果汁（返回值）。机器本身不动，你什么时候想喝什么时候开一次。

---

## 条件判断（if / else）

**大白话**：走到岔路口，**看情况选哪条路**。

```js
let age = 18

if (age >= 18) {
  console.log("成年人")     // 满足条件走这条
} else {
  console.log("未成年")     // 不满足走这条
}
```

- `if` = 「如果」，`else` = 「否则」。
- `>=` `===` `!==` 这些是比较符号，分别是「大于等于」「全等于」「不等于」。
- AI 还会用三目运算符 `条件 ? A : B`，意思是「条件成立取 A，否则取 B」，是 if/else 的简写。

---

## 循环（Loop）

**大白话**：**重复做同一件事 N 次**，不用把代码抄 N 遍。

```js
// 把 1 到 3 依次打印出来
for (let i = 1; i <= 3; i++) {
  console.log(i)
}
// 输出：1、2、3
```

- 常见的是 `for` 循环和 `map`（见下文「数组」）。
- 你多半会看到 `array.map(item => ...)`，意思是「对数组里每个东西都做一遍某事」，非常常用。

---

## 对象（Object）和属性（Property）

**大白话**：一个**带格子的盒子**，每格有个名字（属性名），里面装东西（属性值）。像一张信息卡。

```js
let person = {
  name: "小明",
  age: 20,
  isStudent: true
}

person.name     // 拿到 "小明" —— 用「点」去取某个格子里的东西
person.age = 21 // 改某一格
```

- `name` `age` `isStudent` 叫**属性（Property）**。
- 取值用 `person.name`，读作「person 的 name」。
- AI 常说「给这个对象加个属性」「取一下 `user.id`」，就是这个意思。

---

## 数组（Array）

**大白话**：一串**按顺序排好的格子**，用编号（从 0 开始）去取。

```js
let fruits = ["苹果", "香蕉", "橘子"]

fruits[0]      // "苹果" —— 注意第一个是 0，不是 1
fruits[1]      // "香蕉"
fruits.length  // 3 —— 数组有几个东西
```

- 编号叫**下标（Index）**，从 0 开始是编程界的惯例，一开始会觉得反人类，习惯就好。
- 常见操作：`map`（每个都处理一遍）、`filter`（筛出满足条件的）、`find`（找第一个满足条件的）。

---

## 注释（Comment）

**大白话**：写给**人看**的备注，代码运行时会**忽略**它。AI 写代码时常留注释解释思路。

```js
let age = 20  // 这是单行注释

/*
  这是多行注释
  可以写好几行
*/
```

- `//` 后面到行尾是注释。
- 看代码时，注释往往是你最好的向导。

---

## 小结

| 概念 | 一句话 |
|------|--------|
| 变量 | 贴标签的盒子，装东西用 |
| 数据类型 | 盒子里装的是文字、数字、真假、还是一排/一坨 |
| 函数 | 可复用的菜谱，给原料出成品 |
| if/else | 岔路口，看情况走哪边 |
| 循环 | 重复做 N 次 |
| 对象 | 带格子、有名字的信息卡 |
| 数组 | 按顺序排的一排格子，编号从 0 开始 |
| 注释 | 写给人看的备注，机器忽略 |
